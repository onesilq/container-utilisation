# Container Utilisation

The design prototype for Silq's Container Utilisation Insights, and the developer handoff for its two new pieces.

## Open in your browser

- **Prototype:** https://onesilq.github.io/container-utilisation/container-utilisation.html
- **Developer handoff:** https://onesilq.github.io/container-utilisation/dev-handoff/utilisation-handoff.html (two tabs: FCL button and Container animation)

## What's here

| File | What it is |
|---|---|
| `container-utilisation.html` | The clickable prototype. It's one file with everything built in. |
| `dev-handoff/utilisation-handoff.html` | The developer handoff page, with two tabs: **FCL button** and **Container animation**. Keep the two JS files next to it. |
| `dev-handoff/fcl-unit.js` | Code for the FCL button icon (the small container that fills by space and weight). |
| `dev-handoff/container-animation.js` | Code for the container fill animation shown in the popover. |

## Where to start in the prototype

Projects → open a project → open a shipment (S1, S2 or S3) → hover or click the FCL button next to the container type. **Analytics** in the top bar shows the history charts.

The sample data is made up.
